## Q001：程序、进程、内存、文件与语言

### 原始提问

> 我现在需要学习、理解操作系统。目前我需要掌握进程和程序的概念。
>
> 程序载入内存，内存是怎么样一个布局？
>
> 内存里面的代码段、数据段、堆段、栈段是如何变化的？
>
> 如果我打开了两个 txt 文件，里面存放着不同的内容，它们俩有什么区别？
>
> C 语言和 Rust 语言，Python 和 JavaScript 有什么区别？

### 显式问题

1. 什么是程序，什么是进程？
2. 程序从磁盘到开始执行，中间发生了什么？
3. 典型进程内存布局有哪些区域，它们怎样变化？
4. 打开两个 txt 文件时，磁盘文件、进程和内存之间是什么关系？
5. 四种语言在编译、运行时和内存管理方面怎样区别？

### Q001 的掌握标准

当能够不看正文完成以下任务时，才把学习状态从“待复习”改为“已掌握”：

- 用自己的话解释程序、进程和线程，并说明同一个程序为什么可以启动两次；
- 画出“可执行文件 → 加载器 → 虚拟地址空间 → 主线程”的关系图；
- 画出典型地址空间，并对每个区域说出内容、变化和生命周期；
- 解释编辑器修改但未保存的文字主要在哪里；
- 不使用简单二分法，说明 C、Rust、CPython 和常见 JavaScript 引擎的执行路径；
- 完成第 1 章末尾的情境自测，并能解释答案原因。
